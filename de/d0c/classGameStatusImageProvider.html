Detailed Description

Dynamic image loader for the game's UI components.

Inherits from QQuickImageProvider to serve QImage objects to the QML engine based on the current game state, such as player turns or the "Game Over" screen.

Core method that handles image requests from QML.

Parses the id string to determine which image to return:

  • If id contains "Game Over!", returns the "over" image.
  • If id matches a player name, returns that player's turn icon.
    Parameters
    idThe string after "image://GameStatus/".
    sizeOutput parameter for the original image size.
    requestedSizeThe size requested by the QML Image element.
    Returns
    QImage The requested image or an empty QImage if not found.
